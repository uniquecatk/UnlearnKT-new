# Legacy KT Configs

This directory is kept for backward compatibility.

- Canonical benchmark configs now live under `configs/benchmark/kt/assist2009/`.
- New generated STIRKT sweep variants are written to `configs/benchmark/kt/assist2009/sweeps/`.
- Legacy files here remain runnable, but new work should target the benchmark tree first.
