# Configs

This directory contains the runnable configuration files for `UnlearnKT`.

Recommended starting points:

- `example.jsonc`: minimal demo config
- `proof_of_concept.jsonc`: small proof-of-concept config with `QEFU-KT`
- `benchmark/kt/assist2009/`: benchmark-oriented KT configs

Typical usage:

```bash
python main.py configs/example.jsonc
python main.py configs/proof_of_concept.jsonc
python main.py configs/benchmark/kt/assist2009/class1_baselines.jsonc
```
